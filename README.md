# fit-vault-flutter
A privacy centered, offline fitness tracker for both gym and running. Built using Flutter and Isar NoSQL. No account required.

You can fetch app logs created when running an android device by running the following command in windows:
```bash
adb exec-out run-as com.filiphellgren.fitvault cat app_flutter/<logfile> > app_log.txt
```
Where "<logfile>" is one of the following: "app.log", "foreground.log", "service_lifecycle.log".
